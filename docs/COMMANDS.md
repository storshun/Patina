# Patina command reference

Every command is available as an MCP tool (`patina --mcp`), over TCP as JSON lines
(`{"id":1,"cmd":"<name>","args":{...}}` on 127.0.0.1:7860) and in the in-app Console
(`<name> {json args}`). Generated by `scripts/gen_commands_doc.py` from the live command registry.

Tool results that contain images (`render_view`, `render_uv`, `screenshot_window`, `get_texture`,
`get_material` with `preview`) are returned to MCP clients as PNG image content.

MCP-only tools: `open_gui_window` — when running headless, opens the desktop window with the
current project and switches all further tools to drive it live; `patina_guide {topic}` — the guides
(workflow, mesh, develop, export, batch, painting, parameters), also MCP resources `patina://guide/<topic>`.
MCP prompts: finish_model, develop_textures, game_ready, batch_folder.

### `ping`

Health check.

### `get_state`

Full state snapshot: mesh, layer stack, brush, paint material, tool, camera, view, undo, Blender bridge.

### `open_file`

Opens a mesh (.obj .gltf .glb .fbx .stl .3mf .ply .ptmesh) or a Patina project (.patina).

| argument | type | range, default | description |
|---|---|---|---|
| `path` *(required)* | string |  | Absolute file path |

### `open_mesh`

Loads a mesh and starts a new texture set (or keeps layers when topology matches).

| argument | type | range, default | description |
|---|---|---|---|
| `keep_layers` | boolean |  | Keep painted layers if the mesh has the same topology |
| `path` *(required)* | string |  | Mesh path (.obj .gltf .glb .fbx .stl .3mf .ply .ptmesh) |
| `resolution` | integer | 0 to 8192, default 0 | Texture set resolution per texture set / UDIM tile (512 to 8192, a power of two). 0 = the default (2048); a textured model's texture set grows to its textures' size unless this is given |
| `separate` | boolean |  | (1.2) A file with several meshes (a character's body, clothes, eyes, hair): an object each, with its own layers (true), or one object (false). Default: an object each when there are at most 24 |

### `new_project`

Starts a new project on a primitive mesh (sphere, cube, plane, torus).

| argument | type | range, default | description |
|---|---|---|---|
| `primitive` | sphere \| cube \| plane \| torus |  | Primitive mesh |
| `resolution` | integer | 512 to 8192 | Texture set resolution: 512, 1024, 2048, 4096 or 8192 (default: the preference, 2048) |

### `save_project`

Saves the project (.patina single file).

| argument | type | range, default | description |
|---|---|---|---|
| `path` | string |  | Destination; default: current project path |

### `save_incremental`

Saves the project as the next version next to it: name_v002.patina, _v003...

### `set_resolution`

Changes the texture set resolution (layers are resampled).

| argument | type | range, default | description |
|---|---|---|---|
| `resolution` *(required)* | integer | 512 to 8192 | Resolution per texture set / UDIM tile: 512, 1024, 2048, 4096 or 8192. Layers are resampled. Higher is sharper and takes more memory (a full paint layer: about 85 MB at 2K, 330 MB at 4K) |

### `texture_tiles`

Texture sets per material slot and / or UDIM tiles. Without 'mode' it reports the layout. mode: 'single' (one texture), 'material_slots' (a texture set per slot), 'udim' (a texture per UDIM tile) or 'material_slots_udim'. Paint moves with the layout; undo history is cleared. Every tile has the texture set resolution.

| argument | type | range, default | description |
|---|---|---|---|
| `faces` | boolean |  | Report each tile's face indices too |
| `mode` | single \| material_slots \| udim \| material_slots_udim |  | The layout |

### `export_textures`

Exports the final texture maps as PNG files, or as layered PSD files (format psd: one per map, a layer per Patina layer with its mask, opacity and blend mode; a set per texture set / UDIM tile). Sizes above the texture set render in tiles at full detail (up to 32768).

| argument | type | range, default | description |
|---|---|---|---|
| `base_name` | string |  | Value of $mesh (default: mesh name) |
| `directory` *(required)* | string |  | Output folder |
| `dry_run` | boolean |  | (0.47) Write nothing: answer `plan`, the files it would write, each with what its channels hold, its bits, size and color space (srgb false: data, Blender's Non-Color) |
| `format` | png \| psd |  | png (default) or layered psd |
| `include_ao` | boolean |  | Write the AO map when baked (default true) |
| `include_bent_normal` | boolean |  | Write the bent normal map when baked (default true) |
| `include_thickness` | boolean |  | Write the thickness map when baked (default true) |
| `layer` | integer | 0 to 100000 | Export only this layer / folder (its index), as if soloed |
| `mask` | boolean |  | With layer: export that layer's painted mask as a grayscale PNG |
| `name_template` | string |  | File name template, default "$mesh_$map". Tokens: $mesh $project $map $size $preset $layer |
| `objects` | active \| all |  | (1.2) A scene of several objects: the active object's maps (the default), or every object's shown, each set named after its object ($mesh) |
| `preset` | blender \| gltf \| unreal \| unity |  | Map layout/naming preset |
| `size` | integer | 0 to 32768, default 0 | Output size in pixels; 0 = the texture set's. Up to 32768 (rendered in tiles above the texture set's size) |

### `export_again`

Exports the textures again with the settings of the last export (also stored in the project).

### `reload_mesh`

Reloads the mesh file the project came from (after it was re-exported, e.g. from Blender), keeping the layers: paint is moved to changed UVs, or transferred through 3D when the topology changed.

| argument | type | range, default | description |
|---|---|---|---|
| `path` | string |  | Mesh file (default: the current mesh's file) |

### `import_model_textures`

Brings in the model's own materials (textures and colors of each material slot, and vertex colors, from a .glb, .gltf, .obj with its .mtl, .fbx or .ply) as a paint layer, From the model, at the bottom of the stack (one undo step). Opening a model does this by itself when it has textures, vertex colors or materials that are more than plain gray. (1.2.2) An OBJ or FBX color texture's alpha becomes the opacity channel when the file says nothing about opacity and the alpha cuts out (hair cards, leaves, lace).

| argument | type | range, default | description |
|---|---|---|---|
| `color_alpha` | auto \| opacity \| ignore |  | OBJ / FBX: the color texture's alpha as the opacity. auto (default): when it has see-through and solid parts (a cut-out); opacity: whenever the image has alpha; ignore: never (alpha that holds gloss, as in some Unity assets) |
| `path` | string |  | The model file (default: the open model's file) |

### `create_material`

Creates or updates a user material in the library. type 'procedural' uses a generator (flat two_tone brushed_metal scratched_metal rust concrete wood stone leather fabric tiles plastic car_paint dirt chipped_paint carbon_fiber marble cells emissive_grid diamond_plate hammered corrugated woven bark terrazzo sand moss asphalt camo perforated panels bricks parquet hex_tiles scales grille quilted knit knurling stucco twill skin hair brush_strokes painted_stone painted_wood painted_metal stripes checks dots animal_print cracked_earth flagstone pebbles strata crackle chainmail damascus circuit stained_glass mosaic sequins paper fur feathers leaves rope damask ice crosshatch lace net hair_cards velvet) with params {color_a,color_b,color_c (sRGB 0-1 or #hex), roughness [a,b], metallic [a,b], scale, detail, seed, height, variation, normal_strength, extra[4], emissive, and for every generator warp, warp_scale (wobble), grime, grime_color (dirt in the low parts), wear, wear_color (worn raised edges), opacity, sheen, coat (clearcoat), subsurface (0-1 each), cutout (true: the holes of net, lace, leaves, hair cards, grilles... are see-through)}; list_generators says what each generator's colors and extra values are for. type 'flat' takes color/roughness/metallic/height/emissive/opacity/sheen/coat/subsurface.

| argument | type | range, default | description |
|---|---|---|---|
| `category` | string |  | Category |
| `coat` | number | 0 to 1, default 0 | Flat clearcoat: a smooth varnish over the surface (lacquer, car paint) |
| `color` | array |  | Flat: sRGB color |
| `default_scale` | number | 0.01 to 100 | Pattern repeats per object unit: higher is a smaller pattern |
| `generator` | string |  | Procedural generator name |
| `id` | string |  | Unique id (default derived from name) |
| `metallic` | number | 0 to 1 | Flat metallic: 0 non-metal, 1 metal (in between only along borders) |
| `name` *(required)* | string |  | Display name |
| `opacity` | number | 0 to 1, default 1 | Flat opacity: 1 opaque, 0 invisible |
| `params` | object |  | Generator parameters |
| `roughness` | number | 0 to 1 | Flat roughness: 0 mirror-smooth, 1 fully matte |
| `sheen` | number | 0 to 1, default 0 | Flat sheen: a soft bright rim at grazing angles (velvet, satin) |
| `subsurface` | number | 0 to 1, default 0 | Flat subsurface: light going in and out softened (skin, wax, leaves) |
| `type` | procedural \| flat |  | Material type |

### `import_material_folder`

Imports a folder of PBR texture maps as library materials. Understands ambientCG, Poly Haven, Quixel and Substance export naming, packed maps (Unreal OcclusionRoughnessMetallic / ORM / ARM, glTF metallicRoughness, Unity MaskMap and MetallicSmoothness), OpenGL / DirectX normals, EXR, HDR and 16-bit maps. A Substance Painter export of several texture sets in one folder gives one material per texture set. .sbsar / .spsm files are not readable (Adobe's engine only): export their outputs as images first.

| argument | type | range, default | description |
|---|---|---|---|
| `name` | string |  | Material name (with several texture sets: the name prefix) |
| `normal` | auto \| opengl \| directx |  | Normal map convention (auto: from the file name, or DirectX for Substance's Unreal preset) |
| `path` *(required)* | string |  | Folder path |

| argument | type | range, default | description |

| `color` | array |  | Flat sRGB color [r,g,b] 0-1 or '#rrggbb' |

| `triplanar_blend` | height \| smooth |  | Tri-planar seams: by height (crisp, default) or a smooth cross-fade |
| `triplanar_sharpness` | number | 1 to 16, default 4 | Tri-planar: how quickly the three projections hand over at corners: 1 wide soft blends, 16 crisp seams |

### `export_material_maps`

Bakes library materials and writes their tiling maps (<id>_color, _rmh [r rough, g metal, b height], _normal [OpenGL], _emissive, _opacity [see-through materials], _thumb) plus manifest.json (with each material's average values, sheen, clearcoat and subsurface among them). Used to build the web painter library and Blender's Patina asset library; handy for using Patina materials in other tools.

| argument | type | range, default | description |
|---|---|---|---|
| `directory` *(required)* | string |  | Output folder |
| `format` | png \| jpg |  | Color, normal and glow maps as PNG (default) or JPEG; the rmh map is always PNG |
| `height16` | boolean |  | Also write the height alone as a 16-bit PNG (<id>_height; smooth bump mapping) |
| `ids` | array |  | Material ids (default: see which) |
| `quality` | integer | 1 to 100, default 92 | JPEG quality: lower is smaller and softer |
| `size` | integer | 32 to 4096, default 512 | Map size in pixels |
| `thumbnails` | boolean |  | Also write sphere previews (default true) |
| `which` | builtin \| user \| all |  | Without ids: the built-in materials (default), your own, or both |

## Painting

### `paint_stroke`

Paints one stroke with the current brush/material/tool onto the selected layer (or its mask). Points are [x,y] or [x,y,pressure]. space 'normalized' = 0..1 of the 3D viewport (origin top-left), 'viewport' = pixels, 'uv' = texture coordinates (0..1, origin bottom-left; brush size in texels). Optional brush/material/tool objects are applied first (persistently); (1.2.13) a tool comes first and brings its own brush (feature tool_brushes), so brush arguments change that tool's brush.

| argument | type | range, default | description |
|---|---|---|---|
| `brush` | object |  | set_brush arguments |
| `material` | object |  | set_paint_material arguments |
| `points` *(required)* | array |  | List of [x,y] or [x,y,pressure] |
| `space` | normalized \| viewport \| uv |  | Coordinate space (default normalized) |
| `tile` | integer | -1 to 1023, default -1 | space uv with texture sets / UDIM tiles: the tile (index from texture_tiles); -1 = the UDIM of the first point, else 0 |
| `tool` | paint \| erase \| blur \| clone \| smudge |  | Tool for this stroke |

### `paint_world_points`

Paints a stroke through 3D points (object space). Points are projected through the current camera; hidden points are skipped.

| argument | type | range, default | description |
|---|---|---|---|
| `brush` | object |  | set_brush arguments |
| `material` | object |  | set_paint_material arguments |
| `points` *(required)* | array |  | List of [x,y,z] |

### `fill`

Polygon fill with the current material: mode face | uv_island | connected | mesh | selection. Target faces via 'faces', or 'point' [x,y] (normalized viewport) to pick a face.

| argument | type | range, default | description |
|---|---|---|---|

| `faces` | array |  | Face indices |
| `material` | object |  | set_paint_material arguments |

| `point` | array |  | [x,y] normalized viewport position |

### `pick`

| argument | type | range, default | description |

## Stencils & text

### `set_stencil`

| argument | type | range, default | description |
|---|---|---|---|
| `align` | left \| center \| right |  | Alignment of text lines |
| `clear` | boolean |  | Remove the stencil |
| `color` | array |  | Text color, sRGB [r,g,b] (decal mode paints it) |
| `enabled` | boolean |  | Strokes use the stencil |
| `fit` | boolean |  | Center the stencil and fit it into the view |
| `font` | string |  | Font: sans, sans-bold, serif, mono (bundled), a system font name (list_fonts) or a file path |
| `font_size` | number | 16 to 512, default 128 | Text line height in pixels of the stencil image |
| `invert` | boolean |  | Paint where the stencil is dark / transparent instead |
| `letter_spacing` | number | -64 to 256, default 0 | Extra pixels between letters (negative tightens) |
| `line_spacing` | number | 0.5 to 4, default 1.15 | Line spacing factor |
| `mode` | mask \| decal |  | mask: the stencil only shapes the paint; decal: paints its colors |
| `outline` | number | 0 to 64, default 0 | Text outline width in pixels (0 = none) |
| `outline_color` | array |  | Outline color, sRGB |
| `overlay_opacity` | number | 0 to 1 | How strongly the stencil is shown over the view (display only) |
| `path` | string |  | Image file for the stencil |
| `position` | array |  | Center in the view, fractions [x, y] (0,0 = top left) |
| `rotation` | number | -360 to 360 | Rotation in degrees (clockwise) |
| `save_image` | string |  | Also save the stencil image (e.g. rendered text) as a PNG |
| `scale` | number | 0.01 to 50 | Stencil height as a share of the view height |
| `show_overlay` | boolean |  | Show the stencil over the view |
| `text` | string |  | Make the stencil from text (\n for new lines) |
| `tile` | boolean |  | Repeat the stencil across the view |

### `project_stencil`

Paints the whole stencil onto the surface seen from the current camera in one step (decal projection), with the paint material and channels (decal mode: the stencil's colors). erase=true erases through the stencil instead.

| argument | type | range, default | description |
|---|---|---|---|
| `erase` | boolean |  | Erase through the stencil |

## Models: check, mend, reduce, transform, export

### `mesh_check`

The Mesh Check: what the model is made of (vertices, faces, triangles, parts, material slots, UV islands, size in Blender's axes, area, volume, closed or not, UV coverage) and what is wrong with it: holes, non-manifold edges, bowtie vertices, flipped faces, inside-out parts, degenerate and duplicate faces, open seams (vertices at one place, not joined), loose vertices, specks and floaters, faces without UV space, overlapping UVs, odd scale. Each problem says how many, where (Blender axes) and which mesh_fix mends it. show: the Mesh Check heat map in the viewport; select: select a problem's faces.

| argument | type | range, default | description |
|---|---|---|---|
| `faces` | boolean | default false | List each problem's faces (up to 20000 each) |
| `select` | string |  | Select the faces of this problem (its id from the list), e.g. to mask or delete them |
| `show` | boolean | default false | Switch the viewport to the Mesh Check heat map (red problem, orange warning, blue note) |

### `mesh_fix`

Mends the mesh (see mesh_check): weld (join vertices closer than weld_distance), remove_degenerate, remove_duplicate_faces, remove_loose, remove_small_parts (smaller than small_part_size, default 3% of the model), fix_winding (faces like their neighbors, closed parts facing out), fill_holes (up to fill_hole_edges edges, default 64; the new faces take their border's UVs), or all. The paint moves to the new mesh. It clears the undo history, so a copy of the project is kept first: mesh_fix_revert goes back.

| argument | type | range, default | description |
|---|---|---|---|
| `all` | boolean | default false | Every fix below, with its default settings (the usual first step for a downloaded or generated model) |
| `fill_hole_edges` | integer | 0 to 100000, default 0 | Only holes with up to this many edges. 0 = automatic (64). Raise it for big openings (to print: 512); real openings (a cup's top) also close |
| `fill_holes` | boolean | default false | Close holes with a face (the new faces take their border's UVs) |
| `fix_winding` | boolean | default false | Turn faces like their neighbors; closed parts face out |
| `remove_degenerate` | boolean | default false | Remove faces with no area |
| `remove_duplicate_faces` | boolean | default false | Remove a face on the same corners as another |
| `remove_loose` | boolean | default false | Remove vertices no face uses |
| `remove_small_parts` | boolean | default false | Remove specks and floaters (separate parts smaller than small_part_size) |
| `small_part_size` | number | 0 to 1000000, default 0 | Separate parts smaller than this go, in object units (the diagonal of their box; only parts with under 1% of the faces). 0 = automatic (3% of the model's size). Raise it to remove bigger floaters; lower it to keep small real parts (buttons, eyes) |
| `weld` | boolean | default false | Join vertices at the same place (open seams); needed before holes can be found |
| `weld_distance` | number | 0 to 1, default 0 | Join vertices closer than this, object units. 0 = automatic (1e-5 of the model's size). Larger joins more but can merge separate parts that touch |

### `mesh_fix_revert`

Goes back to the project as it was before the last mesh_fix, mesh_reduce or mesh_transform (mesh, layers and paint).

### `mesh_reduce`

Fewer polygons (decimation): keeps ratio of the triangles (or triangles), the UV layout (seams, material borders and every corner's UV stay, so the textures fit as they are) and, with keep_borders (default), open borders. preview: only say how many triangles it would leave. The undo history is cleared, so a copy of the project is kept first: mesh_fix_revert goes back.

| argument | type | range, default | description |
|---|---|---|---|
| `keep_borders` | boolean | default true | Open borders (a cloth's edge, a cut) don't move |
| `max_error` | number | 0 to 1, default 1 | Stop early rather than let the shape move more than this share of its size: 0.01 = 1%. 1 = always reach the target |
| `preview` | boolean | default false | Only say how many triangles it would leave and the error, without changing the model |
| `ratio` | number | 0.001 to 1, default 0.5 | Share of the triangles to keep: 0.5 halves them, 0.1 keeps a tenth. Lower is lighter but rounder shapes go faceted; the result's error says how far the shape moved |
| `triangles` | integer | 0 to 100000000 | Keep this many triangles instead of a ratio |

### `mesh_transform`

Sizes, turns and places the model: scale (or from_units: the units it was made in, cm, mm, in or ft, to Blender's meters), rotate [x, y, z] in degrees around Blender's axes, origin (keep, center: the middle of its box, base: the middle of its bottom) and ground (the lowest point at height 0). The faces and UVs stay, so the paint does too. A copy of the project is kept first: mesh_fix_revert goes back.

| argument | type | range, default | description |
|---|---|---|---|
| `from_units` | m \| cm \| mm \| in \| ft |  | The units it was made in; it is scaled to Blender's meters (cm: x0.01). Default m (no change) |
| `ground` | boolean | default false | Move it so its lowest point is at height 0 |
| `origin` | keep \| center \| base |  | Where the origin goes: center = the middle of its box, base = the middle of its bottom (for props that stand on the floor). Default keep |
| `rotate` | array |  | [x, y, z] degrees around Blender's axes, applied in that order: [90, 0, 0] stands up a model lying on its back |
| `scale` | number | 1e-06 to 1000000, default 1 | Multiply its size (after from_units) |

### `mesh_collision`

Makes collision shapes for game engines and shows them over the model (green): box (one oriented box), boxes (a box per separate part), hull (one convex hull), parts (a hull per separate part) or pieces (the model split into convex pieces where one hull would hold too much empty space). export_model with collision writes them after the model. clear removes them; show switches the view.

| argument | type | range, default | description |
|---|---|---|---|
| `clear` | boolean | default false | Remove them |
| `concavity` | number | 0 to 1, default 0.05 | Pieces: a piece is split again while its hull holds more than this share of empty space. Lower: more, closer pieces (0.02); higher: fewer, rougher ones (0.15) |

| `max_vertices` | integer | 8 to 255, default 32 | Most corners per hull. Fewer are cheaper and a little smaller than the model; engines like 32 or fewer (PhysX allows 255) |
| `mode` | box \| boxes \| hull \| parts \| pieces |  | box: one oriented box (crates, simple props; cheapest). boxes: a box per separate part. hull: one convex hull (rocks, bottles, round props). parts: a hull per separate part (kits, furniture made of pieces). pieces: the model split into convex pieces where it bends in (chairs, arches, rings, characters; the closest fit). | `resolution` | integer | 8 to 96, default 40 | Pieces: voxels along the longest side. Higher follows thin parts better and is slower; the hulls stand off the surface by about one voxel |
| `show` | boolean | default true | Show them in green over the model |

### `mesh_lightmap_uvs`

| `clear` | boolean | default false | Remove the lightmap UVs |

| `padding` | number | 0 to 64, default 4 | Texels between islands (and from the border) at lightmap_size. Too little lets light bleed between islands; 2 to 4 is usual |
| `source` | uv \| auto |  | uv: the model's own UV islands, repacked (keeps their shapes; best for models with clean UVs; islands that fold are unwrapped again). auto: new charts made for lightmaps by xatlas (for models whose UVs are missing, stretched or a mess, such as scans and generated models; slower on dense models).
