Installing Patina

Patina comes as a prebuilt download for Linux (x86-64) and Windows 10/11 (x64), or as source code you build yourself. It needs an OpenGL 4.5 graphics driver; any GPU from roughly the last ten years has one.

Fedora (and other Linux)

Prebuilt

tar xf patina-*-linux-x86_64.tar.gz     # the version you downloaded, for example 1.2.0
cd patina-*-linux-x86_64
./install.sh                       # installs to ~/.local; no root needed
# PREFIX=/opt/patina ./install.sh  # or somewhere else

This installs ~/.local/bin/patina, a Patina entry in your application menu, the material library, this manual and Patina Web. ./install.sh --uninstall removes it all again. Your own materials, brushes and settings are left in place.

The prebuilt download is made on a current Fedora. It needs that glibc or a newer one, and SDL 3: INSTALL.txt in the download names the exact glibc version. A Fedora Workstation of that release already has the other libraries. If install.sh reports that some are missing:

sudo dnf install SDL3 mesa-dri-drivers libglvnd-egl libglvnd-glx libX11 libXi zenity

On an older system, or a distribution with an older glibc, install.sh says so. Build from source instead, as described below.

WaylandThe prebuilt binary uses X11, so on a Wayland desktop it runs through XWayland, which GNOME and KDE enable by default. Pen pressure still works. For a native Wayland build, build from source as described below. With SDL3-devel installed, Wayland support is built in automatically.

From source

tar xf patina-*-src.tar.gz && cd patina-*/
./scripts/build-fedora.sh          # installs build deps with dnf, builds, runs the tests, installs to ~/.local

Manual build: sudo dnf install gcc-c++ cmake ninja-build SDL3-devel mesa-libGL-devel mesa-libEGL-devel zenity, then cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build. All other libraries are included in the source.

Windows 10 / 11

  1. Unzip patina-<version>-windows-x64.zip anywhere, for example your Downloads folder.
  2. Right-click install.ps1 and choose Run with PowerShell. It copies Patina to %LOCALAPPDATA%\Programs\Patina and adds a Start-menu shortcut. It can optionally add Patina to your PATH. No administrator rights are needed.
  3. Alternatively, run patina.exe straight from the unzipped folder. The folder is portable.

There are two programs in the folder. patina.exe is the normal windowed app. patina-cli.exe is the same program as a console app. Use it for --mcp and --headless, because those modes talk over standard input and output.

Gotcha: SmartScreenThe download isn't code-signed, so Windows may show “Windows protected your PC”. Click More info › Run anyway. PowerShell may also refuse to run install.ps1. If it does, run powershell -ExecutionPolicy Bypass -File install.ps1.
Gotcha: remote desktop and virtual machinesPatina needs a real OpenGL 4.5 driver. Inside a VM or over Remote Desktop, Windows often provides only OpenGL 1.1, and Patina then reports that it can't create a context. Run Patina on the physical machine, or give the VM GPU pass-through.

The Blender add-on

The add-on is the patina_bridge.zip next to the installer.

  • Blender 4.2 and newer: Edit › Preferences › Get Extensions, then the ⌄ menu at the top right, then Install from Disk…, and pick the zip.
  • Blender 3.6 – 4.1: Edit › Preferences › Add-ons › Install…, pick the zip, and enable Import-Export: Patina Bridge.

Then open the Patina tab in the 3D view's sidebar (N). The Blender bridge explains the round trip.

Connecting Claude

The Claude desktop app: click Connect to Claude app in Patina's Blender Link panel, or run patina --setup-claude (Windows: patina-cli.exe --setup-claude). Then restart the Claude app. Claude Code:

# Linux
claude mcp add patina -- ~/.local/bin/patina --mcp
# Windows (PowerShell)
claude mcp add patina -- "$env:LOCALAPPDATA\Programs\Patina\patina-cli.exe" --mcp

Other MCP clients take the same command and arguments in their JSON configuration. Claude & automation covers the details.
