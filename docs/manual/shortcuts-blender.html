Blender keymap reference

If you paint in Blender, switch Patina to the Blender keymap: S samples a color, X flips colors, F resizes the brush, Shift+A adds, Shift+D duplicates, and the middle mouse button orbits. This page lists every key in that keymap. The default Patina keymap has its own page.

Turning it on

  1. Open Edit › Preferences…
  2. Choose Blender keymap. The navigation switches to Blender's as well (middle mouse orbits, Shift + middle pans, Ctrl + middle zooms), and Hold Ctrl while painting to paint with the secondary color is turned on. Both can be changed back separately in the same window.
  3. The choice is saved and kept on the next start. F1 shows the keys of the active keymap.

You can also switch from Edit › Keyboard shortcuts or from the F1 window. Switching keymaps replaces any keys you changed yourself. Individual keys can still be changed afterward in Edit › Keyboard shortcuts.

Tools

Blender's paint tools have no single-key shortcuts, so the Patina keys stay, except where Blender uses the key for something else.

Blur, Pick and Select faces: tool strip

Blur has no key in the Blender keymap since 0.4, because U unwraps, as in Blender. Give it one in Edit › Keyboard shortcuts if you use it a lot.

Picking colorsIn the Blender keymap the Pick tool has no key, because S already samples straight away, without a click. Alt + right-click also picks with any tool.

Gotchas

S samples where the mouse isAs in Blender, S picks the color under the cursor immediately, and the brush then paints that flat color instead of the library material. Click a material again to go back to it.
F no longer frames the modelIn the Blender keymap F resizes the brush. Use Home or Numpad . to frame.
Tab does not hide the panelsIn Blender Tab switches modes, so the Blender keymap uses Ctrl+Space for the distraction-free view.
U no longer selects BlurIn 0.3.1 U was the Blur tool in both keymaps. The Blender keymap now uses it to make an island, as Blender's Unwrap does. Saved Blender keymaps from 0.3.1 are updated on the first start, and keys you changed yourself are kept.
MixingThe keymap and the mouse navigation are separate settings. For example, you can keep Patina's keys and use Blender navigation, or the other way round.
