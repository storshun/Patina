Keyboard and mouse reference

These are the defaults of the Patina keymap. If you come from Blender, switch to the Blender keymap in Edit › Preferences; it has its own reference page. Every key in the Tools, Layers and Application tables can be changed in Edit › Keyboard shortcuts, and View › Navigation switches the mouse navigation to Blender, Maya or ZBrush style (see The interface).

Command line

patina [mesh.glb | .gltf | .fbx | .obj | .stl | .3mf | project.patina]
  --headless        automation server without a window
  --mcp             Model Context Protocol on stdin/stdout (Windows: patina-cli.exe)
  --setup-claude    add Patina to the Claude desktop app's MCP servers, then exit
  --port N          command server port (default 7860, or $PATINA_PORT)
  --no-server       do not open the command server
  --resolution N    default texture resolution (default 2048)
  --verbose         debug logging
  --version

Setting PATINA_FRAME_STATS to a file name makes the window write a line every 120 frames: the frame rate, the time each part of a frame takes on the processor, and the time the 3D view and the whole frame take on the graphics card. Useful when Patina feels slow on a machine.

Setting PATINA_UI_ID_CHECK (to anything) makes Patina check each frame for two buttons or options in one window that Dear ImGui can't tell apart (they would fight over clicks), log each one, and list them for the ui_id_conflicts command. For testing Patina itself.
