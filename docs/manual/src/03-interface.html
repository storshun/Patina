The interface

Patina has two layouts. The Guided layout splits the work into five steps, each with what it needs in front, and a new Patina starts in it. This page describes the Full layout, which shows every panel at once. Switch between them with Guided and Full at the right of the menu bar.

In the Full layout every panel is a dockable window. Drag a panel's tab to rearrange the layout, and Patina remembers it, along with which tool windows were open (Retopology, Assistant, Texel density, Mesh symmetry, Auto texture, Macro recorder, Material Editor). The Retopology window starts as a tab beside Properties; nothing of retopology runs or shows until you choose a retopology tool or its tab. To get the default layout back, use View › Reset the Layout.

The steps' colors

Each step of the Guided layout has a color: Model blue, UVs teal, Bake violet, Paint copper and Export green. The Full layout uses the same colors to show which step a tool, panel or menu belongs to:

  • The tool strip: a stripe beside each group and its name in the group's color (Paint copper, UV teal, Retopo blue). The tool in use is filled with that color.
  • The panels' tabs: a hint of the color on the tab, and a line over the one in front. UV Editor is teal; Layers, Properties, Materials, Brushes and Colors copper; Texture Set and Retopology blue; Blender Link green. Viewport, History, Notes and Console belong to every step and keep no color.
  • The menu bar: the menus of the work follow the steps' order, Mesh, Retopology, UV, Bake, Blender, each underlined in its step's color.

In the Blender layout, choosing a tool or a workspace shows its tab in the Properties editor: the Select tool the Step tab, the Paint tool the Layer tab, a retopology tool the Retopology tab. The pin above the Properties tabs keeps the tab you chose instead (1.2.10). Click it again to unpin.

The welcome window

When Patina starts without a file, the welcome window offers the recent files, the sample model (Suzanne), and a new sphere or cube. It also asks three things:

  • You come from: Blender (the Blender keymap, where the middle button orbits and F3 searches), Maya (Alt with the left, middle and right buttons) or something else (Patina's keys).
  • Your textures go to: the export preset.
  • Layout: Guided or Full.

Untick Show this window on start to skip it, and Help › Welcome Window brings it back. In the Guided layout it appears only the first time, because the Model step offers the same things after that.

Unsaved workPatina asks before anything replaces a project with unsaved changes: New, Open, Open Recent, the autosave, the sample, the welcome window's buttons, a dropped file.

The toolbars

The tool strip on the left and the bars over the 3D view, the UV editor and the layers show icons. They are drawn after the ones painting and 3D programs use, so a brush is a brush and a bucket fills. Rest the pointer on an icon to see its name and shortcut. Right-click a tool to see or change its shortcut.

The retopology tools are always in the strip (with the Retopology feature on). Choosing one shows the zone lines and the quads; its settings are in the bar over the view and in the Retopology window, which opens as a tab if it was closed. You don't need to open the Retopology tab first.

Right-click menus

A right-click opens a menu of what you can do there. In the 3D view it is a click without dragging, so the right-button navigation (zoom with Alt, orbit in the ZBrush preset) still works. Alt+right-click still picks a color, and Ctrl+right-drag still sizes the brush.

Right-click any slider to type its value: the slider turns into a box with the number selected; type, then Enter keeps it and Esc goes back. It is the quick way to set exact values (a brush size of 100, a strength of 0.5). A typed value stays in the slider's range. A left click on a slider works as before, and Ctrl+click types too. Preferences › Features › Type values into sliders switches it off.

Menu items are in Title Case, as in Blender.

Switching off the Right-click menus feature (Edit › Preferences › Features) leaves only the menus Patina had before 0.36: layers, materials, swatches and the UV editor.

Language

Edit › Preferences › Language shows Patina in another language, from a translation file. Anyone can make one; see Translating Patina.

Navigating the view

The axis gizmo in the top right corner of the 3D view shows which way the X, Y and Z axes point as the camera turns: X red, Y green and Z blue, as in Blender and most 3D programs (the letters on the mirror buttons have the same colors). Patina's Y axis points up. The dots without letters are the negative ends.

  • Click an end to look along that axis: X for the right view, Y for the top view, Z for the front view, and the plain dots for the opposite sides. The view jumps there (see Side views).
  • Click the end facing you to see the model from the other side.
  • Drag inside the gizmo to orbit. The wheel zooms over it, as over the rest of the view.

View › Axis Gizmo hides or shows it. Patina Web has the same gizmo.

Side views, and back to your view

The numpad (1 front, 3 right, 7 top, with Ctrl the opposite side), a click on the gizmo and View › View front and the others jump to a side, top or bottom view. Side views are orthographic (no perspective), as in Blender, until you orbit away; then the perspective comes back. Preferences › Mouse can keep the perspective instead, or turn to the side views in a quarter second instead of jumping.

A side view remembers the view you had before it. Numpad 0, or the Back button under the gizmo, takes you back there. Press it again to go back to the side view, so you can flip between the two.

Snapping while orbiting: hold Alt while you orbit with the middle button and the view snaps to the nearest side, top or bottom view as you move the mouse, the way Blender does. Let go of Alt to orbit freely again from there. With the Blender preset, Alt + middle drag snaps from the start; with Patina's preset, Alt + middle drag pans (as in Substance and Maya), so press Alt once the orbit has begun. When you orbit with Alt + left (or the right button in the ZBrush preset), Shift does the snapping. Numpad 0 goes back to where the orbit began.

Quick Favorites

Q opens a pie of your own, as Blender's Quick Favorites menu. It starts with Clear selection, Make island, X mirror, Swap colors, Back to your view and Render image, and two empty places. To fill a place:

  • Right-click a button on the toolbars, or an item in another pie, and choose Add to Quick Favorites. It goes into the first empty place.
  • Choose an empty place in the pie. A list opens with everything a pie can hold: the tools, the view modes, the toggles and every shortcut action. Type to search.
  • In Edit › Preferences › Pie menus, click a place to choose its item, or x to empty it.

Right-click an item in the Quick Favorites pie to replace it or take it out.

Making it yours

  • Preferences: Edit › Preferences… collects the keymap, the mouse navigation, Ctrl-paints-secondary and the UI scale in one window.
  • Blender keymap: choose Blender keymap in Preferences to use Blender's keys (S samples, F resizes the brush, Shift+A adds, Shift+D duplicates, middle mouse orbits…). See the Blender keymap reference.
  • Keyboard shortcuts: Edit › Keyboard shortcuts lists every rebindable action. Click a shortcut and press the new combination. Backspace clears it and Esc cancels. They are saved in keymap.json in the settings folder (Help › About shows where), so you can copy them to another machine.
  • Hide the panels: Tab shows only the viewport and its brush bar. Press Tab again to bring everything back exactly as it was.
  • UI scale: View › UI Scale makes text and controls 75–200% of their normal size. It is applied immediately and remembered.
  • Versions and re-exports: File › Save Incremental (Ctrl+Alt+S) and File › Export Again (Ctrl+Shift+E); see Projects.
  • Recent files: File › Open Recent lists the last 12 projects and meshes, including ones opened from Blender or by Claude. Missing files are grayed out.
  • Remembered between sessions: the brush and its settings, the paint material, the tool, the colors and swatches, symmetry, the UI scale, the navigation preset and the export settings. They live in session.json in the settings folder. Delete it to start fresh.
  • Errors: if saving or exporting fails, Patina says so in a dialog (with a Copy message button) instead of only in the status bar.

View modes

The view combo in the viewport bar shows a single channel, a baked map or a debugging aid. UV checker shows a checker pattern through the model's UVs, which reveals stretching and texel density at a glance. Paint is projected in 3D, so a stretched checker doesn't affect how a stroke looks. It does mean those areas get fewer texture pixels.

Three view modes help with the layout and the parts of the model: Texel Density and UV Stretch are heat maps (see Texel density), and Material Slots colors each Blender material slot differently. Symmetry shows how far each part of the model is from its mirror image across X (see Mesh symmetry check).

PBR Range marks base colors that no real material has, the way Substance's PBR validation does. Red: a non-metal darker than sRGB 30 (darker than charcoal). Blue: a non-metal brighter than 240 (whiter than fresh snow). Orange: a metal darker than 180 (metals reflect at least about half the light). Purple: metallic half-way between metal and non-metal, which is fine along a border, but odd over an area (a few of Patina's own materials, such as the metallic car paints, are half-metal on purpose). Everything else is gray. Engines light such colors oddly: too-dark colors look dirty, too-bright ones glow.

Layer Mask shows the selected layer's mask in black and white: its effective mask, which is the painted mask, the smart mask and any mask effect stack combined, exactly as the layer uses it. Use it while tuning a smart mask's Level and Contrast (see the masks guide). Thickness and Bent Normals show those bakes once they are baked. Bake-Down Check shows, after a bake-down, where the paint found the high-poly and where it had to be guessed (see Baking down). Face Sets shows each face set in its color (see Face sets).

Compare view

To see what a change does, split the view: View › Compare View, or \. The left of the divider shows a snapshot of the textures, the right the live result. Drag the divider to wipe between them. Shift+\ takes a new snapshot, so the usual way is: take a snapshot, change a mask or a material, and wipe. The camera, lighting and brush are shared by both sides, and you can keep painting on the right.

The left side can also show a view mode instead (Compare View › Left: A View Mode), for example the roughness or the normal map next to the lit material. After a bake-down, Left: the high-poly before the bake-down shows the painted high-poly as it was, beside the low-poly with the layers baked down. The snapshot lives only for the session, and a new texture resolution clears it. Claude uses set_compare, and render_view renders the split too.

Notes

Notes are comments pinned to the model, saved in the project: review remarks, to-dos, hand-over notes. Pick the Note tool (N) and click on the model, type, and press Save (Ctrl+Enter). Click a pin with the Note tool to edit it, mark it resolved or delete it. Hover over a pin with any tool to read it. Pins behind the model are drawn faint. The camera moves as with any tool while the Note tool is chosen.

The Notes panel (next to History) lists every note with its number. Click one to turn the camera to the view it was written from, double-click to edit it, and tick it when it's resolved. Resolved shows or hides resolved notes, Pins hides the pins in the view, and Copy all copies the list as a Markdown checklist, for an issue tracker or an email.

Notes keep the author (your user name) and the date. Claude reads and writes them with list_notes, add_note, update_note, delete_note and go_to_note, so it can work through review notes left in a project.

Path traced

The Path traced view mode follows the light the way a renderer such as Blender's Cycles does: real shadows, reflections of the model in itself, and light bouncing between its parts. It uses everything you paint (base color, roughness, metallic, the normal map, emissive, opacity, sheen, clearcoat, subsurface) and the same environment light as the other views, so Shift + right drag turns the light here too. An invisible ground under the model shows its shadow, as in a product photo.

The picture starts grainy and gets cleaner the longer nothing changes; the count in the view's corner says how far it has got. Anything you change (the camera, a stroke, the light) starts it again, with a quick picture first so the view stays smooth. It stops at its number of samples, so the graphics card can rest.

In this mode the bar over the view has a [[icon:path_trace]] Path tracing button with the settings:

  • Samples: where the view stops (512). More removes the last grain in soft shadows and dull metal.
  • Light bounces: how many times light may bounce after the first hit (6). More lights the inside of folds and cavities; 0 is direct light only.
  • Shadow on the ground: the invisible ground with the model's shadow, on or off.
  • Brightest bounce: lower it if bright speckles (fireflies) linger; it costs a little of the brightest glints.

Over MCP: set_view {mode: path_traced}, path_trace for the settings and how far it has got, render_view with samples, and render_image with path_traced.

Rendering an image

File › Render Image… (F12) saves what the viewport shows as a PNG, without the brush circle, seams or wireframe: for a portfolio, a client, or a quick work-in-progress post.

  • Size: any width and height, with HD, 4K and square presets. It doesn't have to match the window.
  • Transparent background: only the model, for compositing or a web page.
  • Anti-aliasing: renders 2–4 times larger and scales down, for smooth edges.
  • Turntable frames: 2 or more renders the model turning once around, as name_0001.png, name_0002.png… ready for a GIF or video tool.
  • Path traced: the render made by the path tracer (see Path traced), with its number of Samples (256 is clean for most models). It takes seconds to minutes; a bar shows how far it has got, and Cancel stops it. The window keeps working meanwhile. No anti-aliasing is needed: the samples smooth the edges. With a transparent background, the ground's shadow is kept as see-through black.

Use Shift + right drag first to turn the lighting to taste.

The console

The Console tab takes the same commands as Claude and the Blender add-on. Type a command name, then optional JSON arguments, for example set_brush {"size": 48}. list_commands lists them all, and the command reference describes each one. It is handy for precise values and for repeating a set-up.

Help windows

F1 opens a shortcut sheet. Help › Manual opens this manual in your browser. Help › About shows the version, the graphics driver and the folders on your machine.
