Scenes: several objects

A project can hold several models at once (new in 1.2): a character's body, its clothes, its eyes and its hair, or a prop and its stand. Each one is an object with its own layers, texture set and undo history. Patina places them in one scene and paints them where they are. It is not a modeler, but it builds a scene out.

The Objects list

The Objects list sits at the top of the Layers panel. Click a row to paint that object. From then on the layers below the list, the UV editor, the bakes and the texture set are that object's. Its own undo history comes with it.

  • The check box shows or hides an object in the 3D view, renders and exports.
  • Double-click a name to rename it.
  • Right-click a row to frame it, show only it, hide the others, put it on the ground, move it back to where it came in, copy it or remove it.
  • Under the list, Placement has the object's location, rotation and scale, to type in or drag.

With one object, the list is a single line with its name and the button to add a model.

Adding models

  • A file with several meshes (glTF, FBX or OBJ) opens as an object for each. A file with more than 24 meshes, like a kit of many small parts, opens as one.
  • File › Add a Model to the Scene (Ctrl+Shift+I), or the button at the right of the Objects list, adds a file beside what is there. A model added to the sphere Patina starts with takes its place.
  • A model dropped on the window while one is open: Patina asks whether to add it or open it instead. Dropped on the Objects list, it is added right away.
  • From Blender, select several meshes and press Send to Patina (see Several objects).

Each object comes in where its file puts it, so clothes exported from the same scene fit the body. Its texture set gets as many texels per meter as the object already open, at most its size. Small parts like eyes get smaller textures, and the detail stays the same across the parts.

Painting the objects

The brush paints the active object. The others are drawn with their own textures, and those in front hide what is behind them from the brush. A stroke that starts on another object does nothing, and the status line says which object it is.

  • Double-click another object in the 3D view to paint it, or right-click it and choose Paint ....
  • Local view (/) shows only the active object. Press it again to show them all.

The Object tool

The Object tool [[icon:move]] (W) moves, turns and scales objects. A click on an object picks it. Its gizmo sits in the middle of the active one:

ModeWhat you drag
MoveAn arrow moves it along that axis. The middle square moves it in the view's plane.
TurnA ring turns it about that axis. The outer ring turns it about the line of sight.
ScaleA handle scales it along its own axis. The middle square scales it evenly.

Press W again for the next mode, or choose it on the tool's bar. Hold Ctrl to snap: moves go in round steps, turns in 15 degrees and scales in tenths. Esc or a right-click while dragging cancels. Each drag is one undo step in that object's history. The bar also has On the ground, which puts the lowest point at height 0, and Where it came in.

G, R and S

As in Blender's Object Mode, you don't have to hit a handle. With the Object tool on and the pointer over the 3D view, press:

KeyWhat the mouse does
GMoves the object in the view's plane.
RTurns it about the line of sight as the pointer goes round its middle.
SScales it evenly. Away from its middle is bigger, toward it smaller.

Then press X, Y or Z to keep to one axis. Press it again to go back to free. Type a number for an exact amount: S 0.5 halves the object, R Z 90 turns it a quarter about Z, and G X 2 moves it 2 along X. Backspace takes a digit back, and Ctrl snaps. A click or Enter keeps the change as one undo step. A right-click or Esc puts the object back. In the Object tool these keys come first: S doesn't pick the Select tool there, and X doesn't swap the colors. They are in Edit › Keyboard Shortcuts with your other shortcuts, in both the Patina and the Blender keymap.

An object turns and scales about its middle. Its texture-space positions don't change when it moves, so fills and procedural masks stay where they are on it.

The project file

Every object is saved in the one .patina file, with its layers, its place and which one was active. Patina 1.1 and older open such a file as its first object only.

Exporting a scene

  • File › Export Model writes every object shown into one file. glTF gets a node for each, where it is, with its own materials and textures. OBJ, STL and PLY get the vertices moved into the scene. Only ... exports the active one.
  • Export Textures writes the active object's maps, or every object's, each set named after its object ($mesh is the object's name).
  • Renders and the path traced view include every object shown.

For agents

list_objects, add_object, select_object, set_object (name, shown, location, rotation, scale, reset, on the ground), remove_object, duplicate_object, isolate_object, frame_object and pick_object. open_mesh takes separate. export_model and export_textures take objects. Every other command works on the active object. The switch is Objects in a scene in Preferences › Features.

Gotchas

  • Each object has a texture set of its own, and that takes graphics memory. Objects you are not painting free their compositing textures until they are painted again.
  • Removing an object can't be undone: its history goes with it. Patina asks first.
  • Retopology, the bake-down and the mesh tools work on the active object.
