Recipes and batches

A recipe is a list of steps that finishes a model: mend it, reduce it, texture it, export it. Run it on the model you have open, or on a whole folder of models at once, as a photo editor applies a preset to a whole shoot. A batch runs in a hidden Patina, so you can keep working, and it never changes the files themselves: the results go to an output folder.

Running a batch

Open File › Batch Process…, pick a recipe, add files or folders (tick Its subfolders too to go deeper) and choose the output folder (by default a patina_out folder beside the first file). Run the batch opens each model in a hidden Patina, runs the steps and moves on. The window shows how far it has got and, for each file, whether it worked; hover a failed one to read why. A file that fails is left, and the rest carry on. Stop after this file ends the batch early.

Apply to the open model runs the same steps on the model you have open instead (its exports go beside its file).

Your own recipes

Edit / copy shows a recipe's steps as text: each is a Patina command and its settings, the same ones Claude and scripts use (see Commands). Change them and Save as my recipe. In the steps, ${name} is the model's name, ${file} its file, ${dir} its folder and ${out} the output folder, so "path": "${out}/${name}.glb" exports each model under its own name. Your recipes are kept in your Patina folder and can be deleted; a copy of a built-in recipe under its id replaces it for you.

[
 {"cmd": "mesh_fix", "args": {"all": true}},
 {"cmd": "mesh_transform", "args": {"from_units": "cm", "origin": "base"}},
 {"cmd": "mesh_reduce", "args": {"ratio": 0.5}},
 {"cmd": "apply_smart_material", "args": {"id": "patina_smart_rusted_iron"}},
 {"cmd": "export_model", "args": {"path": "${out}/${name}.glb", "texture_size": 2048, "lods": [0.5]}}
]

Transform

Mesh › Transform… (and the mesh_transform step) fixes models made in the wrong units or the wrong way round: the units it was made in (centimeters, millimeters, inches, feet, to Blender's meters), a scale, a turn around Blender's X, Y and Z, the origin (the center of its box, or the center of its bottom) and Stand it on the ground. The faces and UVs stay, so painted layers stay too; fill layers projected in 3D follow the new size. As with a fix, Back to before returns to the model as it was.

From Claude and scripts

recipe_list, recipe_save, recipe_delete and recipe_apply work with recipes; batch_run starts a batch (a recipe or steps, files and folders, an output folder), batch_status follows it and batch_cancel stops it. Outside Patina, patina run job.json runs a job with "files" and "per_file" steps the same way; --progress writes a line per finished file (see Automation).
